# Tableau 스터디 기록

[English](README.md) · 한국어

DArt-B 스터디에서 작성한 Tableau 개념 정리와 시각화 실습을 주차별로 정리했습니다.

## 학습 배경과 작성 범위

직접 작성한 학습 메모·문제 풀이·실습 캡처와 스터디 과제 양식이 함께 포함되어 있습니다. 과제 문항과 참고 예시 이미지는 각 출처의 자료이며, 독립적으로 기획한 프로젝트와 구분합니다.

상세 노트는 한국어로 유지했습니다. 빈 답변과 부정확한 설명은 2026-10-29에 보완했습니다. 기존 실습 이미지는 유지하고 새 풀이·수식은 보충 설명으로 추가했으며, 이번에 워크북을 새로 실행한 결과는 아닙니다. 독립적인 대시보드 프로젝트나 워크북 파일은 포함되어 있지 않습니다.

## 확인할 수 있는 실습

- 기본 차트: 차트 구성, 구성비율 계산, 국가·범주별 비교 실습 캡처
- 응용 차트와 필터: 도넛차트·산점도·히스토그램, 기간별 Top N을 위한 컨텍스트 필터 학습 기록

문서에는 직접 수행한 실습 캡처와 과제의 참고 예시 이미지가 함께 있으므로 주변 설명과 함께 확인해주세요.

## 학습 기록과 수정 이력

원래 주차 파일의 이름과 경로를 유지합니다. 각 파일의 History에서 최초 업로드와 이후 수정 내용을 확인할 수 있고, 이번 보완은 새 커밋으로 구분됩니다. [Week 1 History](https://github.com/Seohyun4872/Tableau/commits/main/tableau_week1.md)에는 2026-01-24 최초 업로드 기록이 남아 있습니다. 원본은 별도 폴더가 아니라 Git 과거 버전에서 확인할 수 있습니다.

Tableau_2026의 보완 내용도 같은 주차 파일에 통합했습니다. 해당 저장소의 원래 커밋은 [기존 저장소](https://github.com/Seohyun4872/Tableau_2026)에 유지합니다. 표시되지 않는 로컬 첨부 이미지 참조는 제거하고, 기존 외부 이미지 링크는 유지했습니다.

## 학습 출처

[DArt-B Official](https://github.com/DArt-B-Official)의 과제 템플릿, 문서에 연결된 Tableau 강의, DArt-B Sample Store / Superstore 실습 데이터를 참고했습니다. 상세 출처는 각 문서에 남겨두었습니다. 핵심 설명과 보충 답변은 주차 문서에 연결한 Tableau 공식 문서와 대조했습니다. 실제 데이터에 따른 건수와 화면 결과는 재실행하지 않았습니다.
