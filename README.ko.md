# Tableau 스터디 기록

[English](README.md) · 한국어

DArt-B 스터디에서 작성한 Tableau 개념 정리와 시각화 실습을 주제별로 모았습니다.

## 학습 배경과 작성 범위

직접 작성한 학습 메모·문제 풀이·실습 캡처와 스터디 과제 양식이 함께 포함되어 있습니다. 과제 문항과 참고 예시 이미지는 각 출처의 자료이며, 독립적으로 기획한 프로젝트와 구분합니다.

상세 노트는 한국어로 유지했습니다. 일부 과제는 미작성 상태이며, 계산·LOD·매개변수 문서는 아직 과제 양식의 비중이 높습니다. 현재 독립적인 대시보드 프로젝트나 Tableau 워크북 파일은 포함되어 있지 않습니다.

## 확인할 수 있는 실습

- 기본 차트: 차트 구성, 구성비율 계산, 국가·범주별 비교 실습 캡처
- 응용 차트와 필터: 도넛차트·산점도·히스토그램, 기간별 Top N을 위한 컨텍스트 필터 학습 기록

문서에는 직접 수행한 실습 캡처와 과제의 참고 예시 이미지가 함께 있으므로 주변 설명과 함께 확인해주세요.

## 통합 방식과 원본

두 저장소의 중복 범위를 비교해 주제별로 통합했습니다. 기본 차트는 기존 기록, 응용 차트·필터는 2026 기록을 중심으로 구성하고, 데이터 연결은 양쪽 기록을 조합했습니다.

원본은 [기존 기록](archive/original)과 [2026 기록](archive/2026)에 보존했습니다. 기존 주차 파일은 새 문서로 안내하는 페이지로 남겼습니다. GitHub에서 표시되지 않는 로컬 첨부 이미지는 정리본에서 생략했으며, 원래 참조는 원본 기록에 남아 있습니다. 외부 호스팅 이미지는 기존 링크를 유지합니다.
